About RetroBoard

A personal blog disguised as a relic from the early web.

What is this?

RetroBoard is a static blog template with an imageboard-inspired visual language: compact posts, thread IDs, simple navigation, pale backgrounds, borders, monospace accents, and a deliberately low-fi personality.

Why static?

No database, no framework, and no build step. Drop the folder into GitHub Pages and it works. Edit the post data in assets/app.js and write articles as normal HTML.

Modern underneath

The layout is responsive, semantic, keyboard-friendly, and uses CSS animations sparingly. The search and category filters run entirely in the browser.
